# Open Journal 设计说明

参考：https://blog.google/（Google 官方博客 The Keyword）。提取编辑型博客的布局规律，主题使用站点自己的名称、导航与文章，不包含 Google 标志或固定新闻文案。

- 风格：浅色页面、深灰文字、Google 蓝色系强调，细边框与克制的圆角；字体使用系统无衬线栈，中文保持清晰。
- 桌面：最大内容宽度约 1280px；轻量品牌导航；首页标题留白；首篇文章图文各半，其他文章三列卡片；分类入口为横向标签。
- 手机：单列焦点与文章卡片，标题适当缩小；导航与搜索可展开；正文、表格和代码不造成横向页面溢出。
- 列表：分类、标签、归档、搜索、分页使用真实 ZrLog 数据和链接；无封面提供本地几何插画，无文章显示可操作空态。
- 详情：大标题、作者及日期、宽封面、约 740px 正文栏、标签和相邻文章；使用运行时 Markdown/代码/数学公式样式；不重复摘要。
- 可配置项：introTitle（首页标题）、introText（首页说明）、footerText（页脚说明）；中英文通过 language 属性文件提供默认文案。
- 交互：导航和搜索键盘可操作，清楚的焦点状态，支持 Escape 关闭并返回焦点；尊重减少动画偏好。
- 基准：官方 ZrLog 3.9.2；主题不依赖远程字体、脚本或服务，实际评论插件交互需额外验证。
